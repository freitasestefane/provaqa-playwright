# ProvaQA - Teste de QA

Projeto do teste prático de QA.

## O que tem aqui
- docs/casos-de-teste.md: casos de teste escritos
- docs/bugs.md: bugs encontrados, com prints
- docs/melhorias.md: sugestões de melhoria
- Configuração inicial do Playwright

## Como instalar
npm install
npx playwright install chromium

## Situação da automação
O projeto Playwright está configurado (playwright.config.js e pasta tests), mas os testes automatizados ainda não foram concluídos por falta de tempo. Os casos de teste e os bugs estão documentados na pasta docs.
